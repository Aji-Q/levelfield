## What LevelField claims to be

A pre-trade structural information-asymmetry risk layer for event contracts:
five-dimension anchor classification (D1 outcome control .30, D3 insider
tradability .25, D2 knowledge circle .20, D4 disclosure synchronicity .15,
D5 outcome manufacturability .10), deterministic engine (score =
round(100·Σw·(level−1)/4), bands low<25≤moderate<50≤elevated<75≤high,
graduated circuit breakers CB-1/CB-2, cross-dimension rules R1/R2), no paid
LLM anywhere on the default path, verbatim-evidence verification with
code-level injection defense, MCP server for agents, ScoreRegistry attestations
on Somnia Shannon (0xb8e11dea346f2c961880879606a269db3165bbc7, source-verified
on Blockscout), 16-contract validation (Spearman ρ=0.930, 3 blind runs 16/16
band agreement).

## Hard constraints the project committed to (audit that they hold)

1. No paid LLM API on any default path; MCP protocol lets the caller's model
   classify while code verifies and computes.
2. The model never generates the numeric score; only deterministic code does.
3. Evidence quotes must be verbatim substrings; instruction-like content is
   detected by code and quotes overlapping it are rejected.
4. Truth gates in the demo/site: DreamDEX examples are timestamped snapshots,
   the 3 and the 95 come from separate sources (live vs curated), MCP demo
   submits no order, on-chain provenance completion is future tense until a
   public repo republish happens, no fabricated product UI.
5. Secrets: deploy key only in gitignored .env; nothing secret committed.
